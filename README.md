# 🐍 Game Ular (Snake Game)

## Deskripsi
Game ular interaktif yang dibuat dengan Python dan Pygame. Mainkan sebagai ular yang harus memakan makanan dan menghindari tabrakan.

## Cara Bermain

### Kontrol
- **Panah Atas** (↑): Gerak ke atas
- **Panah Bawah** (↓): Gerak ke bawah
- **Panah Kiri** (←): Gerak ke kiri
- **Panah Kanan** (→): Gerak ke kanan
- **SPACE**: Mulai ulang permainan (saat game over)
- **ESC**: Keluar permainan

### Aturan Permainan
1. **Makan Makanan**: Setiap kali ular makan makanan (merah), panjangnya bertambah 1 dan skor naik 10 poin
2. **Menabrak Dinding**: Jika ular menabrak dinding, permainan berakhir
3. **Menabrak Tubuh Sendiri**: Jika ular menabrak tubuhnya sendiri, permainan berakhir
4. **Tujuan**: Dapatkan skor setinggi mungkin tanpa menabrak apapun

## Instalasi

### Prasyarat
- Python 3.7 atau lebih tinggi
- Pygame

### Install Pygame
```bash
pip install pygame
```

## Menjalankan Game
```bash
python snake_game.py
```
